<h3 align="left">🚀 Featured Projects:</h3>

- 🔍 **[NEXUS-RAG: Agentic Document Search API](https://github.com/anuj-k-bit/Neexxus)** | *Python, FastAPI, LangGraph, Qdrant, Gemini Embeddings, FlashRank, NeMo Guardrails, Portkey, RAGAS, Docker*  
  An agentic document search API that plans queries, retrieves candidates from Qdrant Cloud, reranks top results via FlashRank cross-encoder, and generates cited responses with guardrails and multi-turn thread memory.  
  👉 [Live Demo](https://neexxus-psnrxhvwqhvhctvpqhmmfp.streamlit.app/) · [GitHub Repo](https://github.com/anuj-k-bit/Neexxus)

- 🤖 **[IntelliVend: AI Vending Platform](https://github.com/anuj-k-bit/vendistore)** | *Python, FastAPI, SQLAlchemy, LightGBM, SHAP, PyTorch, Scikit-Learn, LinUCB*  
  Backend and ML engine for an AI-driven smart vending fleet (built at MPOnline). Features 7 microservices, 26 REST endpoints, LightGBM demand forecasting with SHAP drift monitoring, LinUCB dynamic pricing, and 4 guardrailed supervisor agents.  
  👉 [API Docs](https://vendistore-1.onrender.com/docs) · [GitHub Repo](https://github.com/anuj-k-bit/vendistore)

- 📈 **[GradeSense: Recommendations for Paper Machines](https://github.com/anuj-k-bit/Gradesense)** | *Python, LightGBM, MPC, SHAP, SQLite, Pytest*  
  Real-time decision-support system recommending setpoints during industrial grade changes. Integrates physics modeling with LightGBM and MPC optimization to deliver setpoints in under 50 ms while cutting MAE by 50% over baseline.  
  👉 [Live Demo](https://gradesense-8yynkas2wmtq9ckgek3uapp.streamlit.app/) · [GitHub Repo](https://github.com/anuj-k-bit/Gradesense)
